# odin-recipes
This is my first project that I have made after competing the HTML Foundations module in The Odin Project, Foundations. In this project I have made a simple home page that contain the links to 3 different kinds of recipes. These recipes contain general information on what they are and how they can be made.
The recipe pages also contain an image of the finished product.
The Ingredients needed and the steps performed to make the dishes have been clearly stated.
A link back to the home page is also provided at the bottom for easier navigation.
I have implemented what I have learned till now in this project which includes:
1. How to link different pages
2. How to use various heading tags and paragraph tags
3. How to display an image and resize it to our desired result.
4. How to use the ordered list and unordered list tags
5. What to write  in the README.md file and how to connect the github repository to the local machine.
6. How to display the project in not just the local machine but also to showcase it worldwide.
7. How to give credits to the original owners of the pictures as shown below.
